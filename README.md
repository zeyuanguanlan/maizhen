# 脉诊筑基 · 中医脉学学习与背诵工具

本仓库内容为**中医脉学学习与记忆辅助工具**，面向中医学生、师承人员与自学者，用于背诵与复习。

4. **学习数据仅存于本机。** 所有学习进度保存在浏览器 localStorage，不上传服务器；云端同步需使用者自行填写配置，默认关闭。

## 使用

直接打开 `index.html` 即可离线使用。多使用者共用一台设备时，点右上角「学习档案」新建各自档案，学习进度按人分别存档。
