# 脉诊筑基 · 中医脉学学习与背诵工具

本仓库内容为**中医脉学学习与记忆辅助工具**，面向中医学生、师承人员与自学者，用于背诵与复习。

在线使用：https://zeyuanguanlan.github.io/maizhen/

## 功能

- **脉谱**：二十七脉按五类归堆（浮 6 / 沉 4 / 迟数 3 / 形 8 / 势 6），每脉分「认触感 · 记原文 · 辨四维 · 用主病 · 验易混」五层。
- **背诵台**：四言举要 166 行 + 廿七脉诗 72 首，支持逐行朗读、按百分比遮字（30/50/70/100%）、随机换一批遮字、按「必背／熟背／熟读」分级与六纲视图筛选。
- **对比**：任选两脉逐维并排对照；另有**全脉总表**，一屏横向看清二十七脉在「位／数／形／势」四维上的取值。
- **复习台**：按答对次数递推间隔。四言举要与二十七脉诗**分轨独立记录**，互不干扰。
- **自测**：用四维描述反推脉名。
- **学习者档案**：多人共用一台设备时，点右上角「学习档案」各建一份，学习进度按人分别存档，切换不串档；进度只存本机浏览器，关掉重开从上次的地方接着练。
- **皮肤**：内置中国风古典（宣纸 · 墨 · 朱砂 · 青瓷）与科技视觉两套，可随时切换。
